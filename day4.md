Задание 1 — смысл тегов

Объясни своими словами разницу:

A
<strong>Внимание!</strong> - Смысловое выделение важного фрагмента

и

<b>Внимание!</b> - Просто визуальное выделение жирным

B
<em>очень</em> - Смысловое выделение 

и

<i>очень</i> - Визуальное выделение курсивом

C

В чём назначение:

<mark>HTML</mark> - Маркировка важного фрагмента текста

D

Для чего используется:

<small>Примечание</small> - Не значительный фрагмент

Задание 2 — какой тег выбрать?

Для каждого случая выбери подходящий тег и объясни почему.

A

В предложении:

Внимание: файл нельзя удалять.

Слово/фразу «Внимание» нужно сделать семантически важной. - <strong>

B

В статье нужно выделить слово, на которое автор делает смысловой акцент:

Это действительно важно. - <em>

C

На странице результатов поиска найденное слово нужно визуально выделить:

Результат поиска: HTML

Слово HTML должно быть подсвечено. - <mark>

D

Под основной информацией находится небольшое уточнение:

Информация может измениться. - <small>

Задание 3 — цитаты

Какой тег выберешь в каждом случае?

A. Небольшая цитата внутри обычного предложения. - <q>

B. Большая самостоятельная цитата отдельным блоком. - <blockquote>

Варианты:

<q>
<blockquote>

Задание 4 — найди смысловую ошибку

Разработчик написал:

<p>
    Нажми <b>Сохранить</b>, чтобы сохранить файл.
</p>

Он хочет сказать пользователю:

«Сохранить» — это важная инструкция.

Какой тег здесь логичнее использовать вместо <b>? - <strong>

И почему? - Потому-что это по смыслу важная информация
